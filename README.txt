RUMESH & NETHMI - FINAL WEDDING INVITATION

Included:
- index.html - wedding invitation website
- admin.html - RSVP and invitee dashboard
- assets - wedding photos, music and background video
- netlify/functions - RSVP and guest APIs
- netlify.toml - Netlify deployment configuration

NETLIFY DEPLOYMENT
1. Connect this repository to Netlify.
2. Netlify installs @netlify/blobs and deploys the Functions.
3. The production site must be Public so guests can open invitations and submit RSVPs.

RSVP DATA
RSVPs and invitees are stored centrally in Netlify Blobs. The admin dashboard is at /admin.html.

IMPORTANT
The dashboard has no login. Anyone with its URL can view RSVP names, attendance, and messages; create guest links; and manage invitees. Do not share /admin.html publicly if those records should remain private.
